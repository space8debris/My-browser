# My-browser
This is my PyQt6-based Python browser (at the time, it is a large WIP)
I made this to try to make my perfect browser with a custom theme and features

features.
  functional browser
  Built-in MP3 player 
  Sticky note widget 
  A custom theme 
  Vertical and horizontal tab rows
  Floatable and dockable URL and nav bar

I might work on this more if I get motivation. At the time of writing this, I am not too motivated; I might add or fix a bug randomly, but nothing major
